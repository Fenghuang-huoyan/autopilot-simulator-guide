## No active codes right now

As of September 2026, two independent Roblox code/stat trackers — MXBLOX and Robipedia — both
state the same thing: **"There are no active Autopilot Simulator / FSD codes right now."** Neither
site lists any working code, expired or otherwise, for this game.

This is consistent with the game itself: Autopilot Simulator doesn't center its progression on
redeemable codes the way many Roblox tycoon or simulator games do — there's no official Twitter/X
account or Discord server found posting codes as part of a marketing cadence (see
[Community](/community)).

## How to check for new codes yourself

- The game's official Roblox community group, **Plaid Studio** (linked in [Community](/community)),
  is the most direct official channel — any future code would most plausibly be announced there.
- Independent trackers like the two cited above update relatively quickly when new codes appear;
  this page should be updated to cite a specific, dated code the moment one is confirmed working
  by an official or independently-verified source.

## Unconfirmed for now

No code has ever been redeemed or reported here — this page will only ever list a code once it's
been verified against an official source or a currently-active third-party tracker, per the
`sources` requirement every page on this site follows.
