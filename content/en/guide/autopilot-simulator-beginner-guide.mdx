## What the game is

Autopilot Simulator (full title "Autopilot Simulator / FSD") is a Roblox vehicle simulator by
developer Jun4649s, first released December 16, 2022 and still receiving updates as of September
2026. The game's own description calls it "the most realistic Tesla-related game on Roblox": you
drive over 100 ICE, hybrid and electric vehicles across an open map, either manually or by
engaging Autopilot / FSD (Full Self-Driving).

## Your first drive

The overview uses official promotional screenshots; the Autopilot buttons and paid-pass
requirement use the dated creator footage cited on [Controls](/controls/autopilot-simulator-controls).
Menu wording can change with updates.

1. **Spawn a vehicle.** The roster spans more than 100 cars — not only Tesla-styled models, but
   other ICE, hybrid and electric vehicles too. See [Vehicles](/vehicles) for what's confirmed.
2. **Drive manually, or hand off to Autopilot/FSD.** The in-car dashboard has a touchscreen
   styled after Tesla's own center display. In the cited gameplay, Autopilot/FSD requires
   a paid game pass: **Autopilot / Tap To Start** engages it and **Tap To Stop** ends it.
   Check access before buying a pass or looking for the toggle. The dashboard shows a
   blue route visualization while engaged. See [FSD](/fsd/autopilot-simulator-fsd-features) for limits.
3. **Use the in-game phone app for more.** A separate phone-style UI (also modeled on Tesla's own
   app) exposes Control, Alarm, Flash, Light Show and Summon menus. See [Controls](/controls) for
   the full breakdown.
4. **Explore the map.** The official description promises "a spacious map with many buildings and
   roads to explore" — confirmed areas include a downtown district and suburban neighborhoods. See
   [Map](/map).

## Performance note, from the developer directly

The game's own Roblox listing carries a warning: "This game uses development techniques that
cause tremendous lag for low-end devices." The group page recommends using a private server if the
game runs poorly, and states Xbox and mobile are only partially supported.

## Community

The game is run through the Roblox community group **Plaid Studio**, which has more than 3 million
members as of this writing. See [Community](/community) for what's confirmed about the team and
where players gather.
