## Where this list comes from

The developer's official Plaid Studio group description gives a one-line summary: "lane change
function, traffic light detection function, intersection automatic turn function, summon function,
auto park function, AEB function, light show function, music function, etc." That line alone isn't
enough to write a real feature page from, so this list is cross-checked against two creator videos
we watched in full — not just their titles — including an actual in-game Autopilot settings menu
that lists several features the developer's own description never mentions.

## The features, one by one

- **Lane change** — the car changes lanes automatically while self-driving is engaged.
- **Traffic light detection** — the car recognizes traffic lights; the group's own update history
  separately confirms "Traffic lights added" as a real update. **Verified in gameplay**: a
  creator video shows an on-screen "Detect Intersection — AutoTurn Available" prompt actually
  triggering as the car nears a signaled intersection.
- **Intersection automatic turn** — the car can turn automatically at intersections without manual
  input. Same on-screen prompt as above confirms this fires in real play, not just in marketing
  copy.
- **Summon** — move the car remotely from outside it, via the phone app's Summon menu (see
  [Controls](/controls)), including a "Smart Summon (Beta)" mode.
- **Auto park** — the car parks itself.
- **AEB (Automatic Emergency Braking)** — the car brakes automatically to avoid a collision. A
  dedicated creator video titled "Testing the new AEB V3" confirms this feature has shipped at
  least 3 numbered revisions, meaning it's been actively reworked, not a one-off addition — though
  that same video's premise (re-testing a "new" version) implies earlier versions had known
  issues, which is consistent with the other video's caption that Autopilot "almost ran into an
  object" during a separate test.
- **Light show** — a synchronized exterior light display, triggered from the "toy box" per the
  group's update history. This is confirmed by an official in-game badge named "You've started the
  light show!", awarded over 1.2 million times as of this writing.
- **Music function** — an in-car music system (exact controls not detailed in official sources).

## Features the developer's description never mentions

The Autopilot settings menu shown in the "AEB V3" test video lists several toggles that aren't
in the official group description at all — these are confirmed to exist by the video's on-screen
UI, but how each one actually behaves in play is `Unconfirmed`:

- **Sentry Mode** — a real Tesla security feature (records/monitors surroundings while parked);
  present as a toggle in-game, exact in-game effect not shown in the clip we watched.
- **Regenerative Brake** — another real Tesla feature modeled here; toggle exists, effect
  `Unconfirmed`.
- **Auto Speed Limit** — likely caps speed to the posted limit automatically; not demonstrated
  on screen.
- **Parking Sensor** and **Auto Light** — toggles exist; behavior `Unconfirmed`.

## What the path visualization looks like

Once Autopilot/FSD is engaged, the dashboard touchscreen overlays a blue lane path ahead of the
car — visually modeled on real Tesla FSD's own path-prediction display. See
[Controls](/controls) for where this appears on screen.

## Autopilot/FSD is a paid unlock, not free by default

Confirmed from a creator video's own description: engaging Autopilot/FSD requires purchasing a
game pass. See [Controls](/controls) for the exact on-screen toggle text and what it looks like in
practice.

## This is a simulation of the real thing, not the real thing

Autopilot Simulator borrows its name, UI style and feature list from real-world Tesla Autopilot
and Full Self-Driving software, but it is an independent, fan-made Roblox game — it is not made or
endorsed by Tesla, Inc. Nothing on this site should be read as a description of how real Tesla
vehicles behave.

## Unconfirmed for now

Numeric specifics — how far ahead AEB detects hazards, exact lane-change trigger conditions, how
reliable auto-park is — aren't published anywhere official and are marked `Unconfirmed` until a
verifiable source (developer post, or a specific, dated creator test video) turns up.
